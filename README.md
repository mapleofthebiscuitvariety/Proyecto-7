Transformación del gestor de libros del Módulo 6 en una tienda e-commerce: catálogo con filtros,
detalle de producto, carrito persistente, favoritos, tema claro/oscuro y un panel de administración
protegido por login para gestionar productos, precios y stock.

- Requiere instalar Vue CLI para compilar.

- Requiere instalar Bash para ver la lista de productos y precios.

- Si se instala todo, pero todavía no compila: npm install vuetify@^3.7.0 @mdi/js @fontsource/fredoka @fontsource/nunito, esto añade las dependencias faltantes.
